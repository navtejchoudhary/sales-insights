# Master data dictionary

Generated by `uv run python -m sales_insights.generator.masters --as-of YYYY-MM-DD` into `staging/masters/`. Column names and codes follow the company's reference SAP order-to-cash extract, so real data can replace this later with little mapping. All files are UTF-8 CSV with a header row. **Read every column as text** (codes like `05` and `0001001303` have leading zeros).

`masters_manifest.json` is written last. It lists each file's row count and SHA-256 checksum, plus every row where dirt was injected on purpose.

## Differences from the reference extract (on purpose)

- Plant `4020` (Kandy Production Facility) and sales office `K001` (Kandy) get codes; the reference leaves them blank.
- Channel `30` Modern Trade is added for supermarket chains.
- Sales offices added so every province has one: C001, A201, FN05, FN06, FN07.
- Product descriptions are new (the reference descriptions are scrambled); product IDs, groups, types and units follow the reference.
